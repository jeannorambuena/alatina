# PRODUCTION-CHECKLIST.md

## Checklist mínimo después de cada despliegue en Hostinger

### 1. Acceso general
- [ ] Abre https://alatina.cl
- [ ] Carga sin error ni advertencia de seguridad
- [ ] El candado HTTPS aparece correctamente

### 2. Portada
- [ ] La portada real carga correctamente
- [ ] El menú principal funciona
- [ ] El enlace Inicio funciona
- [ ] No hay errores visuales críticos
- [ ] El banner principal funciona

### 3. Páginas clave
- [ ] Quiénes somos
- [ ] Calendario escolar
- [ ] Noticias
- [ ] Contacto
- [ ] Documentos / Información escolar

### 4. Móvil
- [ ] La portada carga bien en móvil
- [ ] El menú móvil abre y cierra bien
- [ ] No hay elementos cortados o fuera de pantalla
- [ ] El banner móvil se puede cerrar correctamente

### 5. WordPress admin
- [ ] Se puede entrar a /wp-admin
- [ ] No hay errores visibles en el escritorio
- [ ] Los enlaces permanentes quedan guardados si fue necesario

### 6. DNS y caché
- [ ] alatina.cl resuelve correctamente
- [ ] www.alatina.cl se revisa si aplica
- [ ] Se limpia caché de Hostinger si hubo cambios visibles

### 7. Cierre
- [ ] Se registra el cambio en CHANGELOG.md
- [ ] Se crea tag de producción si corresponde
- [ ] Se deja respaldo o referencia del despliegue
